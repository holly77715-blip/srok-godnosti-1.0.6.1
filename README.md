# Сроки годности

Офлайн-страница для подсчёта сроков годности: быстрый расчёт, записи с примечаниями и экспорт отчёта в txt.
Работает как сайт на GitHub Pages и после первого открытия — без интернета.

## Уведомления о сроках

- За 40 дней до конца срока (и для просроченных) приложение показывает уведомление по каждой позиции, затем повторяет его каждые 12 часов.
- Вверху страницы — плашка «Истекающие сроки» со всеми такими позициями.
- Чтобы уведомления работали, нажмите «Включить уведомления» и разрешите их.
- На Android установите приложение (Chrome → меню → «Установить приложение»): тогда проверка идёт и в фоне
  (Chrome сам решает, когда запускать её, не чаще раза в 12 часов). Если в списке больше 5 позиций, приходит одно общее уведомление.
- Без сервера гарантировать точное время фоновых уведомлений нельзя: если приложение давно не открывали, Chrome может запускать проверку реже.

## Отделы

Поле «Отдел» необязательное. Записи с отделом группируются по отделам, без отдела — внизу. Список «Показать отдел» над таблицей позволяет выбрать один отдел, «Без отдела» или «Все отделы». Отдел попадает в txt-отчёт и читается при импорте.
